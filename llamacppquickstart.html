llama.cpp Quickstart

Build llama.cpp from source, download a GGUF model and run a local LLM from the command line. Tested on Ubuntu 26.04 LTS.

What you need
A recorded terminal session, start to finish
  • Ubuntu (or Debian) Linux (last tested on Ubuntu 26.04 LTS) with sudo access. Every command below is plain Linux shell — no GUI required.
  • Network access on the first run only. llama-cli downloads the model for you.
  • A few GB of free disk for the source tree, the build output and the model weights.
  • No GPU required. The 0.8B model below runs on CPU, so this works on any machine with a modern processor.
Setup and first run
Copy and paste in order
$ cd /home/ubuntu/Public
$ sudo apt install -y git build-essential cmake libcurl4-openssl-dev libssl-dev
$ git clone https://github.com/ggml-org/llama.cpp
$ cd llama.cpp
$ cmake -B build
$ cmake --build build --config Release
$ ./build/bin/llama-cli -hf ggml-org/Qwen3.5-0.8B-GGUF --chat-template-kwargs '{"enable_thinking":false}'
loading model / downloading ggml-org/Qwen3.5-0.8B-GGUF ...
llama_context: n_ctx = 4096
