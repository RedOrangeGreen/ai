1. Getting Started

AI coding works best when you treat the model like a junior developer: give it context, constraints, examples, and a clear goal. 

// Good starter prompt
You are helping me build a small web app.
Tech stack: HTML, CSS, JS.
Goal: A responsive landing page.
Constraints:
- No external frameworks
- Keep CSS under 200 lines
- Include a hero section and 3 feature cards

2. Prompt Patterns

These reusable patterns help you get consistent results across tasks. 

// Pattern: "Improve this"
Improve the following function.
Keep the same behaviour.
Explain the changes after the code.

function add(a, b) {
  return a + b;
}

3. Debugging with AI

AI is excellent at spotting logic errors, missing edge cases, and mismatched assumptions. 

// Pattern: "Find the bug"
Here is a function that behaves incorrectly.
Describe the bug, then fix it.

function getUser(id) {
  if (id = 0) {
    return null;
  }
  return { id };
}

4. Refactoring Workflows

AI can refactor code into cleaner, more modular structures while preserving behaviour. 

// Pattern: "Refactor safely"
Refactor this code.
Keep behaviour identical.
Split into smaller functions.
Add comments explaining each part.

5. Generating Components

Use AI to generate UI components, backend handlers, or utility functions quickly. 

// Pattern: "Generate a component"
Generate a responsive card component.
Inputs:
- title
- description
- icon
Output:
- HTML
- CSS
- JS (if needed)
