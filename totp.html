How it works

Standard, not proprietary — this implements RFC 6238 TOTP with HMAC-SHA-1 (the default used by Google Authenticator, Microsoft Authenticator and most other apps), and also supports HMAC-SHA-256 and HMAC-SHA-512 for services that require them. A secret added here produces identical codes to the same secret in those apps.

Base32 secret — services usually show it as a QR code; "enter this key" reveals the text form (characters A–Z and 2–7).

30-second window — the code changes every 30 seconds (adjustable). The ring shows time left; wait for the ring to fill for a fresh code.

Fully offline — hashing happens in this page; nothing is sent anywhere. If you save the secret, it stays only in this browser's storage.

Security — a secret is the same as a password. Only use this on a trusted, private device, and keep a backup (Google Authenticator lets you export / transfer accounts).
